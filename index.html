A scroll-triggered, CSS-only animation system.

MOGP Motion works with the browser's native scroll-driven animation API, without JavaScript. As you scroll down, each example animates in on its own.

View on GitHub README

fade

The simplest effect. Only opacity changes — position and size stay fixed.

data-mogp-motion="fade"No additional attribute needed. Works with default values.

<div data-mogp-motion="fade">...</div>

scale-up

The element grows from a smaller size up to its full size.

data-mogp-motion="scale-up"Default starting size is 70% (data-mogp-scale-start="70").

<div data-mogp-motion="scale-up">...</div>

slide-up

The element slides in from below.

data-mogp-motion="slide-up"Default distance is 50px (data-mogp-slide-distance="50").

<div data-mogp-motion="slide-up">...</div>

slide-down

The reverse of slide-up — the element slides in from above into place.

data-mogp-motion="slide-down"Shares the same data-mogp-slide-distance attribute as slide-up; default distance is 50px.

<div data-mogp-motion="slide-down">...</div>

data-mogp-scale-start comparison

The value is literally the element's starting size — 90% is a subtle effect, 50% produces a much more dramatic grow-in.

scale-start = 90

Starts at 90% size — subtle effect.

scale-start = 50

Starts at 50% size — pronounced effect.

<div data-mogp-motion="scale-up" data-mogp-scale-start="50">...</div>

data-mogp-slide-distance comparison

The same slide-up effect, with different slide distances.

slide-distance = 30

A short, subtle slide.

slide-distance = 150

A long, dramatic entrance.

<div data-mogp-motion="slide-up" data-mogp-slide-distance="150">...</div>

data-mogp-motion-start / data-mogp-motion-end

Controls when, within the element's time on screen, the animation starts and ends.

start=0 · end=20

Appears quickly, as soon as the element touches the viewport.

start=60 · end=100

Appears slowly, after the element is well into the viewport.

<div data-mogp-motion="fade" data-mogp-motion-start="60" data-mogp-motion-end="100">...</div>

Same values on short vs. long content

Percentages aren't a fixed pixel distance — they're a proportion of the element's own cover timeline. The same start=10, end=50 values correspond to a different scroll distance in the short and long card below.

start=10 · end=50 — short card

This single-line card completes over a short scroll distance, relative to its own height.

start=10 · end=50 — long card

This card uses the same start and end values, but contains a lot more text. In the real world a card might look like a bullet list or a long paragraph — as its size grows, so does the element's total time on screen. That means the same percentage values stretch over a much longer scroll distance than on the short card — the animation progresses at the same rate, but feels different. Scroll slowly to compare the two cards.

<div data-mogp-motion="fade" data-mogp-motion-start="10" data-mogp-motion-end="50">...</div>

prefers-reduced-motion

If the user has "reduce motion" enabled at the OS level, all animations are disabled and content appears directly, with no shift.

This card is animated too, just like the othersBut with "reduce motion" on, it appears directly, with no slide.

Things to know

  • Elements visible on initial loadElements already inside the viewport when the page loads are evaluated against their current position on the scroll timeline. Their starting state may differ from elements that enter the viewport later.
  • Horizontal scroll containers aren't supportedThe system tracks the vertical axis by default. It won't trigger as expected inside horizontally scrolling containers (e.g. a carousel).
  • Only one motion typeAn element can only be assigned a single data-mogp-motion value.
  • Browser supportTracks native animation-timeline: view() support. In unsupported browsers, content renders without animation, fully visible.
