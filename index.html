Effects

The four motion types, with defaults.

fade

Only opacity changes.

data-mogp-motion="fade"

scale-up

Grows from a smaller size to full size.

data-mogp-motion="scale-up"

slide-up

Rises from below while fading in.

data-mogp-motion="slide-up"

slide-down

Drops from above while fading in.

data-mogp-motion="slide-down"

Timing

Start and end windows, plus long content.

data-mogp-motion-start / -end

When, within the element's time on screen, the animation starts and ends. 0–100, steps of 5. Defaults 10 and 50. Percentages are relative to each element's own timeline.

start 0 · end 20

Finishes almost immediately.

start=0 end=20

start 0 · end 50

Custom timing window.

start=0 end=50

start 0 · end 100

Plays across the whole time on screen.

start=0 end=100

start 10 · end 50

Custom timing window.

start=10 end=50

start 20 · end 60

Custom timing window.

start=20 end=60

start 30 · end 70

Custom timing window.

start=30 end=70

start 50 · end 100

Starts late, ends at the bottom.

start=50 end=100

Starts late, ends at the bottom.

Combinations

Options work together. Also: will-change and wrapper elements.

scale-up + timing

Scale 50, window 0–60.

scale-start=50 start=0 end=60

slide-down + distance + timing

100px, window 5–40.

distance=100 start=5 end=40

slow fade

Fade across the full pass.

fade start=0 end=100

will-change opt-in

Promotes the element to its own layer up front.

data-mogp-motion-will-change

Using your own transform

translate and scale are independent properties, so they can clash with your own. Put your transform on an inner element.

I have my own rotate(-3deg)
<div data-mogp-motion="slide-up">
  <div style="transform: rotate(-3deg)">...</div>
</div>

Notes

Accessibility and support.

Accessibility

If your OS is set to reduce motion, every example on this page appears fully visible with no animation. Browsers without scroll-driven animations show the content as normal.

Browsers

Chromium 115+ and Safari 26+ support scroll-driven animations; Firefox support is behind a flag at the time of writing. See the README for details.
